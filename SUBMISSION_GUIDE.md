# SIH Submission Structure

This repository follows the requested SIH submission-oriented structure.

## Structure

- `submission/` — final presentation and demo materials
- `src/` — primary source-code entry point / source organisation
- `docs/` — project documentation
- `assets/screenshots/` — project screenshots and photos
- `README.md` — project overview
- `requirements.txt` — project dependencies
- `.gitignore` — ignored files
- `LICENSE` — project license

Existing project components such as `backend/`, `frontend/`, `ai/`, `data/`, `infra/`, `graph/`, `mock_service/`, and `tests/` are retained because they are part of the working DeCypher implementation.
